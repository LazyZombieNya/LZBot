# LZBot

Telegram-бот на базе ИИ-модели Gemini, отвечающий в личных сообщениях и групповых чатах с разными настройками поведения.

## 🚀 Возможности

- Интеграция с API Gemini.
- Персонализированные подсказки (prompts) для разных типов чатов: личный, групповой.
- Краткие, понятные и по существу ответы.
- Обработка вопросов на русском языке.

## 📦 Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/LazyZombieNya/LZBot.git
   cd LZBot

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` в корне проекта и добавьте в него:

   ```env

    TELEGRAM_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
    GEMINI_API_KEY=YOUR_GEMINI_API_KEY
    GEMINI_MODEL=gemini-2.0-flash

    AI_PROMPT_TGM=Ты — Telegram-бот, основанный на ИИ. Отвечай кратко, понятно и по существу. По возможности старайся не превышать лимит сообщений Telegram (менее 4096 символов). Отвечай на русском языке.
    AI_PROMPT_PM=Ты персональный помощник. Общайся один на один, запоминай контекст.
    AI_PROMPT_GM=Ты находишься в групповом чате. Каждый вопрос может приходить от другого человека. Отвечай по существу, учитывай, что собеседники могут быть разными. Не путай их между собой.
    AI_PROMPT_IS_RELEVANT_QUESTION="Можешь ли ты дать полезный и точный ответ как ИИ, не имеющий тела, ощущений, доступа к физическому миру или частной информации людей. \n Если вопрос адресован явно человеку или требует физического опыта, личных ощущений или действий, напиши строго: Нет.\n Если это нейтральный вопрос, на который ты можешь ответить сам, напиши строго: Да. \n"

   ```

## ▶️ Запуск

Запустите бота:

```bash
python main.py
```

Или используйте команду `python main.py` в терминале.
